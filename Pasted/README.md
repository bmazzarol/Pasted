# Pasted

**Text files, baked into the binary.**

A source generator that turns text files into string constants at compile time, for source generators and AOT binaries that have no assembly directory to read from at runtime.

[![Nuget](https://img.shields.io/nuget/v/Pasted)](https://www.nuget.org/packages/Pasted/)

```shell
dotnet add package Pasted
```

[Getting started](https://bmazzarol.github.io/Pasted/getting-started.html) - [Full documentation](https://bmazzarol.github.io/Pasted/)

## How to use

Add the files to embed to the project:

```xml
<ItemGroup>
    <AdditionalFiles Include="wwwroot\index.html" />
    <AdditionalFiles Include="wwwroot\css\site.css" />
    <AdditionalFiles Include="wwwroot\js\site.js" />
</ItemGroup>
```

Enable embedding for each file in `.editorconfig`:

```editorconfig
[wwwroot/index.html]
embed = true

[wwwroot/css/site.css]
embed = true

[wwwroot/js/site.js]
embed = true
```

Reference the generator as a build time only dependency:

```xml
<ItemGroup>
    <PackageReference Include="Pasted" Version="x.x.x">
        <PrivateAssets>all</PrivateAssets>
        <IncludeAssets>runtime; build; native; contentfiles; analyzers; buildtransitive</IncludeAssets>
    </PackageReference>
</ItemGroup>
```

The generator writes a static class with one constant per file:

```csharp
// the EmbeddedFiles static class is generated by the source generator
const string html = EmbeddedFiles.Index;
const string css = EmbeddedFiles.Css;
const string js = EmbeddedFiles.Js;
```

## Configuration options

| Option       | Type    | Default                     | Description                                     |
|--------------|---------|-----------------------------|-------------------------------------------------|
| `embed`      | boolean | `false`                     | Embeds this file                                |
| `namespace`  | string  | `Pasted`                    | Namespace of the generated class                |
| `class_name` | string  | `EmbeddedFiles`             | Name of the generated class                     |
| `name`       | string  | file name without extension | Name of the constant for the file               |
| `public`     | boolean | `false`                     | Makes the generated class and its fields public |

## What it does not do

- Only text files are embedded. Binary files are not supported
- Nothing is embedded unless `embed = true` is set for that file
- Files are not watched. Changing an embedded file requires a rebuild
